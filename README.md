# Cloud Computing Basic Project
UniTS, Valeria De Stasio, SM3800074

The objective of this project is to evaluate and compare the overall performance of a cluster built upon virtual machines (VMs) and a cluster built upon containers.
To do so, the report contains the steps for setting up VMs and containers (the Dockerfile and docker-compose are included as separated files), the benchmark tests utilized and the observations and analysis of the performance tests.
